# PR-voorstel: Wetboek — vereenvoudiging veroordelingen

Aanbevolen pull request titel:

docs(wetboek): vereenvoudig veroordelingen — afkoopregeling en Nederlandstalige terminologie (max 100 maanden)

Korte omschrijving voor de PR:

- Volledig Nederlandstalige vereenvoudiging van het wetboek (terminologie: Poging / Plegen / Meervoudig).
- Afkoopregeling toegevoegd: volledige afkoop alleen, maximaal 40 maanden, €20.000 per maand.
- Maximumcelstraf ingesteld op 100 maanden.
- Medeplichtigheid standaard 75% en afrondingsregel ten gunste van de verdachte.
- Inbeslagname-regels en openstaande-boetes-drempel (€100.000) toegevoegd.
- Procentuele verhogingen/verlagingen verwijderd; "Plegen tegen ambtenaar in functie" toegevoegd als vaste tabelrij waar relevant.

Branch: simplify/veroordelingen
Bestand met wijzigingen: docs/wetboek.md (op deze branch)
Commit message gebruikt: "docs: pas wetboek aan op basis van gebruikersinspiratie — Nederlandstalig, afkoopregeling toegevoegd, medeplichtigheid en inbeslagname"

Wat kun je nu doen:
- Open een pull request op GitHub vanuit branch `simplify/veroordelingen` naar je hoofdbranch met bovenstaand titel en omschrijving.
- Of laat mij weten of je wilt dat ik nog extra aanpassingen maak in de branch voordat je de PR opent.
